# Internacionalización (i18n)

## Resumen

El portfolio soporta dos idiomas: **Español (ES)** e **Inglés (EN)**, con cambio instantáneo sin recarga de página mediante un botón en la barra de navegación.

## Arquitectura

El sistema de traducción se basa en Angular Signals y un servicio inyectable global, sin dependencias externas.

```
src/app/i18n/
├── translations.ts         # Datos de traducción ES/EN + tipos TypeScript
└── translation.service.ts  # Servicio global con signal reactivo
```

## Archivos Clave

### `translations.ts`

Define la estructura tipada de todas las traducciones y los datos para cada idioma.

```typescript
export type Lang = 'es' | 'en';

export interface Translations {
  nav: { about, projects, contact };
  hero: { greeting, role, tagline, cta };
  about: { title, bio[], techTitle };
  projects: { title, subtitle, items[] };
  contact: { title, subtitle, labels, placeholders, errors, submit, success };
  footer: { rights };
}

export const TRANSLATIONS: Record<Lang, Translations> = { es: {...}, en: {...} };
```

### `translation.service.ts`

Servicio singleton (`providedIn: 'root'`) que gestiona el idioma activo.

```typescript
@Injectable({ providedIn: 'root' })
export class TranslationService {
  private currentLang = signal<Lang>('es');   // Idioma por defecto
  lang = this.currentLang.asReadonly();        // Signal de solo lectura
  t = computed<Translations>(() => TRANSLATIONS[this.currentLang()]);  // Traducciones reactivas

  toggleLang(): void {
    this.currentLang.update(l => l === 'es' ? 'en' : 'es');
  }
}
```

## Cómo se usa en componentes

Cada componente inyecta el servicio y accede a las traducciones via `i18n.t()`:

```typescript
// En el componente
i18n = inject(TranslationService);

// En el template
{{ i18n.t().hero.greeting }}       // "Hola, soy" | "Hi, I'm"
{{ i18n.t().contact.submit }}      // "Enviar mensaje" | "Send message"
```

### Componentes que usan traducciones

| Componente | Campos traducidos |
|---|---|
| **Navbar** | Links de navegación (About, Projects, Contact) + botón toggle |
| **Hero** | Greeting, rol, tagline, texto del CTA |
| **About** | Título de sección, bio (4 párrafos), título tech stack |
| **Projects** | Título, subtítulo, título/descripción de cada proyecto |
| **Contact** | Título, subtítulo, labels, placeholders, errores, botón submit, mensaje de éxito |
| **Footer** | Texto de derechos reservados |

## Botón de Cambio de Idioma

Ubicado en la barra de navegación, visible en todos los tamaños de pantalla.

- Muestra `"EN"` cuando el idioma activo es español (indica a qué idioma se cambiará)
- Muestra `"ES"` cuando el idioma activo es inglés
- Estilo: borde dorado, texto dorado, hover invierte colores (fondo dorado, texto oscuro)

```html
<button class="lang-toggle" (click)="i18n.toggleLang()">
  {{ i18n.lang() === 'es' ? 'EN' : 'ES' }}
</button>
```

## Cómo Añadir un Nuevo Idioma

1. Añade el código al tipo `Lang` en `translations.ts`:
   ```typescript
   export type Lang = 'es' | 'en' | 'fr';
   ```

2. Añade el objeto de traducciones completo en `TRANSLATIONS`:
   ```typescript
   export const TRANSLATIONS: Record<Lang, Translations> = {
     es: { ... },
     en: { ... },
     fr: { ... },  // Nuevo idioma
   };
   ```

3. Actualiza la lógica de toggle en `translation.service.ts` para soportar más de dos idiomas:
   ```typescript
   private langs: Lang[] = ['es', 'en', 'fr'];

   toggleLang(): void {
     const current = this.langs.indexOf(this.currentLang());
     const next = (current + 1) % this.langs.length;
     this.currentLang.set(this.langs[next]);
   }
   ```

4. Actualiza el botón en `navbar.html` para mostrar el idioma siguiente.

## Cómo Añadir Nuevos Textos Traducibles

1. Añade la clave a la interfaz `Translations` en `translations.ts`
2. Añade el valor en los objetos `es` y `en` dentro de `TRANSLATIONS`
3. Usa `{{ i18n.t().seccion.clave }}` en el template del componente

## Características Técnicas

- **Sin recarga**: el cambio de idioma es instantáneo gracias a Angular Signals
- **Type-safe**: la interfaz `Translations` garantiza que todas las claves existen en todos los idiomas
- **Sin dependencias**: no usa `@ngx-translate`, `@angular/localize` ni ninguna librería externa
- **Idioma por defecto**: español (`'es'`)
- **Rendimiento**: `computed()` solo recalcula las traducciones cuando cambia el idioma
